# JEKYO templates

Ready-made app templates for [JEKYO](https://github.com/jekyo/jekyo).
Each directory holds one `jekyo.yaml` with `description:`/`icon:` metadata;
`index.yaml` is the catalog listing.

```sh
jekyo templates        # browse
jekyo init postgres    # start from one
```

Contributions welcome: add `<name>/jekyo.yaml`, register it in `index.yaml`.
